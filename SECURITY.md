# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/seike460/kagemusha/security/advisories/new) (the repository's **Security** tab → **Report a vulnerability**). Don't open a public issue or pull request for a vulnerability.

Include the affected version or commit, the steps to reproduce, and the impact you expect.

## 脆弱性の報告

脆弱性は、GitHub の [private vulnerability reporting](https://github.com/seike460/kagemusha/security/advisories/new)（リポジトリの **Security** タブ → **Report a vulnerability**）から、非公開で報告してください。公開の Issue や pull request には書かないでください。

影響する版かコミット、再現の手順、想定する影響を添えてください。
